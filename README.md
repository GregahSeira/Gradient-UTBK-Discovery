# Gradient UTBK: Share Progress Belajar (discovery prototype)

Prototype satu file (`index.html`) untuk menguji fitur "bagikan progress belajar" dari profil ke anak studytwt.

## Cara jalanin
- Buka `index.html` di browser (butuh internet untuk font Google dan html2canvas dari cdnjs).
- Atau pakai link artifact yang dipublish.

## Titik masuk share
1. Profil: tombol **Bagikan progress**
2. Profil > Habit: kartu ajakan (hari ini / minggu ini)
3. Latihan Soal (menu Mastery): **Selesaikan sesi latihan (demo)** lalu **Bagikan sesi ini**
4. Profil > Achievement: ikon bagikan di badge yang sudah diraih

## Studio share
- Periode: sesi / hari ini / minggu ini
- Gaya kartu: Study Log, Statistik, Poster, Menuju Kampus
- Ukuran: Feed 4:5, Persegi 1:1, Story 9:16 (ekspor PNG 1080px)
- Data bisa di-toggle: durasi, soal & akurasi, materi, tingkat kesulitan, streak, kampus impian, badge, level & EXP, username
- Caption otomatis (bisa diedit), salin link profil, privasi link, share ke X
- Tombol **Kasih masukan** menghasilkan teks jawaban + jejak aktivitas untuk dikirim lewat DM

## Catatan
- Semua data contoh (ada toggle "Data rajin" dan "Data baru mulai").
- Link profil publik dan pengaturan privasi hanya simulasi UI.
